Process to setup Migration:

----------------------------PART 1 ------------------------

1. Intialise the express, and install dependeices regarding.
   npm install --save-dev sequelize-cli express
   npm install --save pg pg-hstore
   npm install dotenv
2. Setup Package.json
3. Setup up .env and setup Database in Supabase.
4. Config backend server make connection with Supabase.

----------------------------- PART 2 ------------------------

5. Created Models directory and Created User Model
6. Config migration config.js and .sequelizerc for Migration
7. Created Migration and  Implement the logic of migration
8. Run the Migration
